## نظرة عامة

L-LEX محرك بحث قانوني سريع وثلاثي اللغات في تشريعات العراق وإقليم كوردستان. اكتب رقم مادة أو كلمة مفتاحية بالكردية السورانية أو العربية أو الإنجليزية، واحصل على المادة الكاملة — شروطها وعقوبتها — في أقل من ثانية، دون أي تسجيل أو حساب.

## المميزات

- 🔍 **بحث فوري** — برقم المادة (بالأرقام اللاتينية `251` أو العربية المشرقية `٢٥١`)، أو بالكلمات المفتاحية، أو بنوع العقوبة
- 🌐 **ثلاث لغات** — الكردية السورانية والعربية والإنجليزية مع دعم كامل لاتجاهي الكتابة
- ⚖️ **أحد عشر قانونًا مفهرسًا** — ٨٨٥ مادة في تشريعات العراق وإقليم كوردستان، منها قانون العقوبات العراقي رقم ١١١ لسنة ١٩٦٩ (٥٠٣)، وقانون قوى الأمن الداخلي لكوردستان (٩٠)، وقوانين البيشمركة/العسكرية من الحزمة الثلاثية اللغة؛ وتظهر التغطية الجزئية بوضوح عند عدم اكتمال قانون ما
- 🌓 **وضع داكن حقيقي** — لوحة ألوان داكنة مصممة بعناية، لا مجرد عكس للألوان
- 🔒 **بلا تسجيل** — المفضلة والتفضيلات تُحفظ في متصفحك فقط؛ والجزء الوحيد من جهة الخادم هو عداد زوار اختياري

## البدء

يتطلب **Node.js ≥ 24** (انظر `.nvmrc`).

```sh
npm install
npm run dev             # خادم التطوير
npm run build           # فحص الأنواع + بناء الإنتاج
npm run data:normalize           # إعادة بناء content/normalized/
npm run data:classify            # إعادة تصنيف العقوبات
npm run data:import-translations # استيراد الترجمات الإنجليزية/العربية المقبولة
npm run data:index               # إعادة بناء search-index.json
npm run seo:sitemap              # إعادة توليد public/sitemap.xml لـ Search Console
```

لعدّاد الزوار على Vercel، أضف تكامل Upstash Redis واضبط `UPSTASH_REDIS_REST_URL` + `UPSTASH_REDIS_REST_TOKEN` (وتعمل أيضًا متغيرات `KV_REST_API_URL`/`KV_REST_API_TOKEN` القديمة). اضبط `SITE_URL` عند توليد خريطة الموقع لدومين مختلف.

## البيانات ومنهجية الترجمة

الكردية السورانية هي **لغة المصدر الموثوقة** للـ٥٩٣ مادة في `content/source/`؛ والمصطلحات القانونية العربية الواردة بين قوسين تُعامل كمراسٍ اصطلاحية معتمدة. وتضيف حزمة `law_data_json/` المورّدة ٢٩٢ مادة ثلاثية اللغة عبر تسعة قوانين أخرى، ليصل المجموع المطبّع إلى ٨٨٥ مادة. وتبلغ الترجمات الإنجليزية والعربية الحالية ٣٠٢ مادة فقط وهي كلها موسومة **آلية / بانتظار المراجعة البشرية** — ولا يُعرض أي منها على أنه مُراجع قانونيًا. فئات العقوبات (الإعدام، السجن، الغرامة، الطرد، …) مستخرجة بمطابقة أنماط مُدقّقة على مواد المصدر الـ٥٩٣.

## إخلاء المسؤولية القانوني

> **L-LEX أداة مرجعية غير رسمية، وليست استشارة قانونية.** النص الرسمي للجريدة الرسمية / برلمان كوردستان هو المعتمد عند أي اختلاف.
