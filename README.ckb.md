## پوختە

L-LEX بزوێنەرێکی گەڕانی خێرا و سێ‌زمانییە بۆ ماددەکانی یاساکانی عێراق و هەرێمی کوردستان. ژمارەی ماددەیەک یان وشەیەکی سەرەکی بە کوردیی سۆرانی، عەرەبی، یان ئینگلیزی بنووسە و لە کەمتر لە چرکەیەکدا ماددە تەواوەکە — مەرجەکانی و سزاکەی — وەربگرە، بەبێ هیچ هەژمارێک و بەبێ چوونەژوورەوە.

## تایبەتمەندییەکان

- 🔍 **گەڕانی دەستبەجێ** — بە ژمارەی ماددە (بە ژمارە لاتینییەکان `251` یان عەرەبییەکان `٢٥١`)، بە وشەی سەرەکی، یان بە جۆری سزا
- 🌐 **سێ زمان** — کوردیی سۆرانی، عەرەبی، و ئینگلیزی، لەگەڵ پشتگیری تەواوی ڕاست-بۆ-چەپ و چەپ-بۆ-ڕاست
- ⚖️ **دوو یاسای تەواو** — یاسای سزادانی عێراقی ژمارە ١١١ی ساڵی ١٩٦٩ (٥٠٣ ماددە) و یاسای هێزەکانی ئاسایشی ناوخۆی کوردستان (٥٤ ماددە)، پۆلێنکراو بەسەر ١٢ جۆری سزادا
- 🌓 **دۆخی تاریکی ڕاستەقینە** — پاڵێتێکی تاریکی دیزاینکراو، نەک هەڵگەڕاندنەوەی ڕەنگەکان
- 🔒 **بەبێ هەژمار و بەبێ سێرڤەر** — ماڵپەڕێکی تەواو ستاتیک؛ دڵخوازەکان و هەڵبژاردنەکانت تەنیا لە وێبگەڕەکەی خۆتدا هەڵدەگیرێن

## تەکنەلۆژیاکان

| توێژ     | هەڵبژاردە                                           |
| -------- | --------------------------------------------------- |
| زمان     | TypeScript (دۆخی توند)                              |
| چوارچێوە | Vite + TypeScript ی ڕەسەن — بەبێ فرەیمۆرک           |
| ستایل    | Tailwind CSS v4 بە تایبەتمەندییە لۆجیکییەکان بۆ RTL |
| گەڕان    | FlexSearch (لای کڕیار، بەبێ سێرڤەر)                 |
| فۆنت     | Vazirmatn Variable (لاتینی/عەرەبی/سۆرانی یەکگرتوو)  |
| هەڵگرتن  | تەنیا `localStorage` — بەبێ هەژمار و داتابەیس       |
| هۆستکردن | هەر هۆستێکی ستاتیک / CDN                            |

## دەستپێکردن

پێویستی بە **Node.js ≥ 24** هەیە (بڕوانە `.nvmrc`).

```sh
npm install
npm run dev             # سێرڤەری گەشەپێدان
npm run build           # پشکنینی جۆرەکان + بنیاتنانی بەرهەمهێنان
npm run data:normalize  # دووبارە بنیاتنانەوەی content/normalized/
```

## داتا و شێوازی وەرگێڕان

کوردیی سۆرانی **زمانی سەرچاوە و بنەڕەتییە** بۆ هەردوو یاساکە؛ ئەو زاراوە عەرەبییانەی لەناو کەوانەکاندا هاتوون وەک زاراوەی یاسایی فەرمی و بڕیاردەر هەڵدەگیرێن. وەرگێڕانی ئینگلیزی و عەرەبی ماددەکان بە وەرگێڕانی ئامێری بەرهەم دەهێنرێن و **نیشانەیەکی ڕوونی دۆخی وەرگێڕان** لەسەر هەر ماددەیەک دەردەکەوێت ("وەرگێڕانی ئامێری — چاوەڕوانی پێداچوونەوەی مرۆیی"). پۆلێنی سزاکان (سێدارە، زیندانی، غەرامە، دەرکردن، …) بە شیکردنەوەی دەقی هەر ٥٥٧ ماددەکە دەرهێنراون.

## ئاگادارکردنەوەی یاسایی

> **L-LEX ئامرازێکی ناڕەسمی سەرچاوەیە و ڕاوێژکاری یاسایی نییە.** لە کاتی هەر جیاوازییەکدا، دەقە فەرمییەکەی ڕۆژنامەی فەرمی / پەرلەمانی کوردستان بڕیاردەرە.
