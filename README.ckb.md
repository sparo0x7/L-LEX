## پوختە

L-LEX بزوێنەرێکی گەڕانی خێرا و سێ‌زمانییە بۆ ماددەکانی یاساکانی عێراق و هەرێمی کوردستان. ژمارەی ماددەیەک یان وشەیەکی سەرەکی بە کوردیی سۆرانی، عەرەبی، یان ئینگلیزی بنووسە و لە کەمتر لە چرکەیەکدا ماددە تەواوەکە — مەرجەکانی و سزاکەی — وەربگرە، بەبێ هیچ هەژمارێک و بەبێ چوونەژوورەوە.

## تایبەتمەندییەکان

- 🔍 **گەڕانی دەستبەجێ** — بە ژمارەی ماددە (بە ژمارە لاتینییەکان `251` یان عەرەبییەکان `٢٥١`)، بە وشەی سەرەکی، یان بە جۆری سزا
- 🌐 **سێ زمان** — کوردیی سۆرانی، عەرەبی، و ئینگلیزی، لەگەڵ پشتگیری تەواوی ڕاست-بۆ-چەپ و چەپ-بۆ-ڕاست
- ⚖️ **١١ یاسا** — ٨٨٥ ماددە لە یاساکانی عێراق و هەرێمی کوردستان، لەوانە یاسای سزادانی عێراقی ژمارە ١١١ی ساڵی ١٩٦٩ (٥٠٣)، یاسای هێزەکانی ئاسایشی ناوخۆی کوردستان (٩٠)، و یاساکانی پێشمەرگە/سەربازی لە باندڵی سێ‌زمانی دابینکراو؛ کەمبوونەوەی بەشەکانی یاساکان بە ڕوونکردنەوە نیشان دەدرێت
- 🌓 **دۆخی تاریکی ڕاستەقینە** — پاڵێتێکی تاریکی دیزاینکراو، نەک هەڵگەڕاندنەوەی ڕەنگەکان
- 🔒 **بەبێ هەژمار** — دڵخوازەکان و هەڵبژاردنەکانت تەنیا لە وێبگەڕەکەی خۆتدا هەڵدەگیرێن؛ تەنیا پارچەیەکی سێرڤەرلێس بۆ ژمارەی میوانە گشتییەکان هەیە

## دەستپێکردن

پێویستی بە **Node.js ≥ 24** هەیە (بڕوانە `.nvmrc`).

```sh
npm install
npm run dev             # سێرڤەری گەشەپێدان
npm run build           # پشکنینی جۆرەکان + بنیاتنانی بەرهەمهێنان
npm run data:normalize           # دووبارە بنیاتنانەوەی content/normalized/
npm run data:classify            # دووبارە پۆلێنکردنی سزاکان
npm run data:import-translations # وەرگرتنی وەرگێڕانە وەرگیراوەکانی EN/AR
npm run data:index               # دووبارە بنیاتنانەوەی search-index.json
npm run seo:sitemap              # نوێکردنەوەی public/sitemap.xml بۆ Search Console
```

بۆ ژمارەی میوانەکان لە Vercel، یەکخستنی Upstash Redis زیاد بکە و `UPSTASH_REDIS_REST_URL` + `UPSTASH_REDIS_REST_TOKEN` ڕێکبخە (شێوازی کۆنی `KV_REST_API_URL`/`KV_REST_API_TOKEN`یش کاردەکات). کاتێک sitemap بۆ دۆمەینێکی تر دروست دەکەیت `SITE_URL` ڕێکبخە.

## ئاگادارکردنەوەی یاسایی

> **L-LEX ئامرازێکی ناڕەسمی سەرچاوەیە و ڕاوێژکاری یاسایی نییە.** لە کاتی هەر جیاوازییەکدا، دەقە فەرمییەکەی ڕۆژنامەی فەرمی / پەرلەمانی کوردستان بڕیاردەرە.
